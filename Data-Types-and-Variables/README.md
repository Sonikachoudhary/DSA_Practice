# C++ Data Types and Variables for DSA

Run these programs one at a time. Each `.cpp` file has its own `main()` function.

From PowerShell, for example:

```powershell
g++ .\01_int.cpp -o .\01_int.exe
.\01_int.exe
```

Replace `01_int` with the file name you want to run. The `.exe` files are generated locally and should not be committed.

## Programs

1. `01_int.cpp` — whole numbers
2. `02_long_long.cpp` — larger whole numbers
3. `03_float.cpp` — decimal values
4. `04_double.cpp` — decimal values with greater precision
5. `05_char.cpp` — one character
6. `06_bool.cpp` — true or false
7. `07_string.cpp` — text
8. `08_sum.cpp` — a simple DSA-style sum using `long long`

Check problem constraints before choosing a type. A sum or product can exceed the range of the input values, so use `long long` when needed.
